<h1 align="center">Deep Live Studio</h1> <p align="center"> <strong>ИИ ЛИЦО И ГОЛОС В РЕАЛЬНОМ ВРЕМЕНИ</strong><br> Единый центр управления выключателем, заменой лица и голоса — в первое время. </p> <p align="center"> от Syrex · v1.0.0 </p>

Deep Live Studio — это настольное приложение с единым интерфейсом, объединяющее замену лица (Camera) и конвертацию голосов (Voice) в первое время в одну студию с общим дашбордом, мониторингом ресурсов и выводом в OBS/виртуальную камеру.

Интерфейс

Приложение состоит из следующих разделов (боковое меню):

Студия — главный дашборд: статус модулей, быстрый запуск, системные ресурсы (CPU/GPU/RAM/VRAM)
Камера — управление выключателем, заменой лица и виртуальным видео в первое время
Голос — управление микрофоном, RVC и преобразованием голоса
Сцены — пресеты/сценарии с сохранёнными настройками камеры и голосов.
Модели — управление моделями лиц (GPEN, DFM и т. д.) и голосовыми моделями (.pth / .index)
OBS / Вывод — настройка выходных устройств камеры и звука во внешних приложениях
Настройки — общие настройки приложения
Логи — журнал работы модулей
О программе — информация о версии и авторе

С дашборда «Студия» можно открыть каждый модуль отдельно («Открыть камеру» / «Открыть голос») либо запустить всё сразу кнопками Быстрый запуск и Запустить всё . Статус каждой модуля (Камера, Замена лица, Голос (RVC), OBS / Вывод) отображается в первую очередь.

⚠️ Дисклеймер

🎭 Камера / Face Swap — замена лица в первое время

Основано на Deep-Live-Cam (InsightFace/inswapper) с доработками:

Реалистичная замена лица по одному референсному фото, без обучения модели
Поддержка GPEN, DFM и других моделей. Улучшение/замена лица.
Ускорение инференса через TensorRT (FP16)
Плавное совмещение краёв лица (оперённое/пуассоновая смесь)
Маска для рта — сохранение движений рта и зубов.
Расширенное покрытие головы (лоб, скулы, подбородок) для более естественного вида.
Виртуальная камера ( OBS/Unity Capture ) — подхватывается OBS, Zoom, Discord, Google Meet и др.
Гибкие настройки и улучшение качества картинки
Экспериментальные модули FaceFusion и LivePortrait для полной замены головы (пока не в первое время)
🎙️ Голос / RVC — конвертация голосов в первое время

Основано на RVC (преобразование голоса на основе поиска) Realtime VST :

Высокое качество звука, живая конвертация голоса с низкой задержкой.
Поддержка голосовых моделей .pth и .index
Настройка голоса в первую очередь
Работает с любыми приложениями (звонки, стримы, игры) через виртуальный микрофон
Инструменты для подготовки датасета и обучения самостоятельной голосовой модели ( dataset, train, prepare_source_voice_training)
Веб-интерфейс ( webui/ go-webui) и десктопный графический интерфейс реального времени ( realtime_gui/ go-realtime-gui)
Готовые сборки запускаем под CPU / CUDA 11.8 / CUDA 12.8 ( requirments_cpu_py312, requirments_cu118_py312, requirments_cu128_py312)

Запуск

Проще всего запустить студию стола профессором Deep_Live_Studio.vbs— он открывается deep_live_studio.pyчерез venv\Scripts\pythonw.exeбез консольного окна.

чёрный

Проект состоит из общей обработки Deep Live Studio и двух модулей ( Camera, Voice) с различными зависимостями Python — ставьте их отдельно, каждый в свой venv.

интернет
Python 3.11–3.14 (для видео-части рекомендуется 3.14)
Python 3.12 (для голосовой части)
pip, git
ffmpeg
Графический процессор NVIDIA с CUDA (опционально, но настоятельно рекомендуется для реального времени)
0. Deep Live Studio (общая игра)

Создаём venvв корне репозитория — именно из него студию запускает Deep_Live_Studio.vbs:

баш
python -m venv venv
venv\Scripts\activate
pip install -r requirements_studio.txt   # если такого файла нет — уточните зависимости deep_live_studio.py

Студия из его интерфейса запускает и управляет модулями Cameraи модулями Voice, которые должны быть установлены отдельно (см. ниже).

1. Камера (замена лиц)
баш
cd Camera
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt

Загрузите модели ( gfpgan-1024.onnx, inswapper_128_fp16.onnx) и поместите их в индикатор models, затем запустите:

баш
python run.py --execution-provider cuda   # или cpu / directml / openvino / coreml
2. Голос (преобразование голоса в реальном времени)
баш
cd Voice
python -m venv .venv
# Windows:
.venv\Scripts\activate

# Выберите нужный файл зависимостей под своё железо:
pip install -r requirments_cu128_py312.txt   # NVIDIA, CUDA 12.8
# pip install -r requirments_cu118_py312.txt # NVIDIA, CUDA 11.8
# pip install -r requirments_cpu_py312.txt   # без GPU

Запуск:

баш
python realtime_gui.py

Либо вскормите готовый ярлык Запустите Voice Changer (Windows).

Использование
Через Deep Live Studio (рекомендуется)
Запустите Deep Live Studio .
На вкладке Студия нажмите Открыть камеру — выберите исходное фото лица и замену.
Нажмите Открыть голос — выберите обучаемую голосовую модель (.pth/.index) и обработайте микрофон.
Либо запустите оба модуля, нажмите кнопку Запустить всё / Быстрый запуск .
Во вкладке OBS / Вывод настроек подключения камеры и виртуального микрофона.
Выберите эту виртуальную камеру и микрофон в качестве источника в вашем стриминговом/звонковом приложении (OBS, Zoom, Discord, Google Meet и т.д.).

Статус работы каждой модуля (Камера, Замена лица, Голос (RVC), OBS/Вывод), видимый на дашборде «Студия» в первый раз, там же — загрузка CPU/GPU/RAM/VRAM.

Модули по отдельности

Камеру и голос также можно запускать напрямую, без общей проверки Studio — см. Camera/run.pyи Voice/realtime_gui.py.
