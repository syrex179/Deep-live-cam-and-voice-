# 📖 О проекте

**Deep Live Studio** — это настольное приложение, объединяющее
технологии искусственного интеллекта для обработки видео и аудио
в режиме реального времени.

Проект создан как единый центр управления двумя основными модулями:

- 🎭 **Camera** — обработка видео и замена лица.
- 🎙️ **Voice** — преобразование голоса с использованием RVC.

Вместо запуска нескольких отдельных приложений пользователь получает
единую студию с общим интерфейсом, мониторингом системных ресурсов
и возможностью вывода обработанного видео и аудио в сторонние программы.

> ⚡ **Одна студия. Два ИИ-модуля. Новые возможности.**

# 🏗️ Архитектура проекта

Deep Live Studio построен по модульному принципу.

Основное приложение отвечает за графический интерфейс и управление
компонентами, а Camera и Voice работают как отдельные модули.

Это позволяет устанавливать и обновлять их независимо друг от друга.

```text
Deep-live-cam-and-voice/
│
├── 📄 Deep_Live_Studio.vbs
│   └── Запуск приложения без окна консоли
│
├── 📄 deep_live_studio.py
│   └── Главное графическое приложение
│
├── 📄 requirements_studio.txt
│   └── Зависимости основной студии
│
├── 📁 venv/
│   └── Виртуальное окружение студии
│
├── 📁 Camera/
│   ├── 📄 run.py
│   ├── 📁 models/
│   ├── 📄 requirements.txt
│   └── 📁 venv/
│
└── 📁 Voice/
    ├── 📄 realtime_gui.py
    ├── 📁 models/
    ├── 📄 requirements_*.txt
    └── 📁 .venv/
```

> ℹ️ Структура репозитория может изменяться в процессе разработки.

# 🚀 Установка

## 1️⃣ Клонирование репозитория

Откройте PowerShell или командную строку:

```powershell
git clone https://github.com/syrex179/Deep-live-cam-and-voice-.git
```

Перейдите в папку проекта:

```powershell
cd Deep-live-cam-and-voice-
```

---

## 2️⃣ Установка Deep Live Studio

Создайте виртуальное окружение:

```powershell
python -m venv venv
```

Активируйте его:

```powershell
venv\Scripts\activate
```

Установите зависимости основной студии:

```powershell
pip install -r requirements_studio.txt
```

> Если файл `requirements_studio.txt` отсутствует в текущей версии
> проекта, проверьте зависимости, используемые в `deep_live_studio.py`.

---

## 3️⃣ Установка Camera

Перейдите в каталог Camera:

```powershell
cd Camera
```

Создайте виртуальное окружение:

```powershell
python -m venv venv
```

Активируйте окружение:

```powershell
venv\Scripts\activate
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

### 📦 Установка моделей

Поместите необходимые модели в каталог:

```text
Camera/
└── models/
    ├── gfpgan-1024.onnx
    └── inswapper_128_fp16.onnx
```

> Названия, расположение и список необходимых моделей зависят
> от текущей версии модуля Camera.

---

## 4️⃣ Установка Voice

Перейдите в каталог Voice:

```powershell
cd ..\Voice
```

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.venv\Scripts\activate
```

### 📦 Установка зависимостей

Выберите подходящий файл в зависимости от конфигурации системы.

#### 🎮 NVIDIA CUDA 12.8

```powershell
pip install -r requirments_cu128_py312.txt
```

#### 🎮 NVIDIA CUDA 11.8

```powershell
pip install -r requirments_cu118_py312.txt
```

#### 💻 Только CPU

```powershell
pip install -r requirments_cpu_py312.txt
```

> ℹ️ Проверьте названия файлов в своей версии репозитория.
> В некоторых версиях может использоваться написание `requirements`
> вместо `requirments`.

# ▶️ Запуск

## 🏠 Запуск Deep Live Studio

После установки зависимостей перейдите в корневую папку проекта
и запустите:

```text
Deep_Live_Studio.vbs
```

Скрипт запускает главное приложение через Python из виртуального
окружения студии.

Это позволяет использовать приложение без отдельного окна консоли.

### Альтернативный запуск

```powershell
venv\Scripts\python.exe deep_live_studio.py
```

---

## 📷 Запуск Camera отдельно

Перейдите в каталог Camera:

```powershell
cd Camera
```

Запустите модуль с использованием NVIDIA CUDA:

```powershell
python run.py --execution-provider cuda
```

Для запуска с использованием процессора:

```powershell
python run.py --execution-provider cpu
```

В зависимости от конфигурации также могут поддерживаться другие
провайдеры выполнения, например DirectML или OpenVINO.

---

## 🎙️ Запуск Voice отдельно

Перейдите в каталог Voice и активируйте его виртуальное окружение.

Запустите графический интерфейс:

```powershell
python realtime_gui.py
```

При наличии соответствующей сборки можно использовать готовый ярлык
для запуска Voice Changer.

# 🎬 Использование приложения

## 🏠 1. Главная студия

После запуска Deep Live Studio откройте раздел **«Студия»**.

На главном экране доступны:

- Быстрый запуск подготовленной конфигурации.
- Запуск всех доступных модулей.
- Переход к настройкам камеры.
- Переход к настройкам голоса.
- Мониторинг состояния компонентов.
- Просмотр загрузки системных ресурсов.

---

## 📷 2. Настройка камеры

1. Откройте раздел **«Камера»**.
2. Выберите исходное изображение лица.
3. Выберите необходимые параметры обработки.
4. Настройте качество и производительность.
5. Запустите обработку видеопотока.
6. При необходимости настройте виртуальную камеру.

---

## 🎙️ 3. Настройка голоса

1. Откройте раздел **«Голос»**.
2. Выберите голосовую модель `.pth`.
3. При наличии подключите соответствующий файл `.index`.
4. Выберите микрофон.
5. Настройте параметры преобразования.
6. Запустите обработку голоса.

---

## 🎥 4. Подключение к OBS Studio

Deep Live Studio может использоваться совместно с OBS Studio
и другими приложениями, поддерживающими внешние устройства.

### Подключение видеопотока

1. Запустите обработку видео в Deep Live Studio.
2. Откройте OBS Studio.
3. Добавьте источник захвата видео.
4. Выберите доступную виртуальную камеру.
5. Настройте разрешение и параметры изображения.

### Подключение аудио

1. Запустите преобразование голоса.
2. Настройте виртуальный аудиовыход.
3. Откройте настройки аудио в OBS Studio.
4. Выберите нужное аудиоустройство.

> ℹ️ Доступность виртуальной камеры и виртуального микрофона
> зависит от установленного программного обеспечения и настроек системы.

# 🎙️ Обучение собственных голосовых моделей

Модуль Voice включает инструменты для подготовки аудиоданных
и обучения собственных голосовых моделей.

В проекте могут использоваться следующие компоненты:

```text
Voice/
├── dataset/
├── train/
└── prepare_source_voice_training/
```

### Рекомендуемый порядок работы

1. Подготовьте качественные записи голоса.
2. Убедитесь, что в записях отсутствует лишний фоновый шум.
3. Подготовьте аудиоданные.
4. Выполните необходимые этапы обучения.
5. Полученную модель подключите к Voice.

Подробные инструкции находятся в документации модуля:

- `Voice/README`
- `Voice/docs`

> Используйте только собственные записи голоса или материалы,
> на использование которых у вас есть соответствующее разрешение.
