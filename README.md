🎭 Deep Live Studio
ИИ-замена лица и голоса в реальном времени

Deep Live Studio — настольное приложение, объединяющее технологии замены лица и преобразования голоса в едином интерфейсе.

Проект предоставляет централизованное управление модулями Camera и Voice, мониторинг системных ресурсов, настройку виртуальных устройств и интеграцию с OBS Studio и другими приложениями.

🚀 Разработчик: Syrex

📦 Версия: v1.0.0

🖥️ Платформа: Windows

📸 Обзор проекта

Deep Live Studio разработан как единый центр управления инструментами ИИ для работы с видео и аудио в реальном времени.

Приложение позволяет запускать и настраивать отдельные модули или использовать их одновременно через общий интерфейс.

📷 Camera — замена лица в реальном времени

Модуль Camera основан на технологиях Deep-Live-Cam, InsightFace и модели inswapper.

Он предназначен для замены лица в видеопотоке без необходимости предварительного обучения собственной модели.

Возможности Camera
🎭 Замена лица
Замена лица с использованием одного исходного изображения.
Обработка видеопотока в реальном времени.
Поддержка различных моделей обработки лица.
Настройка параметров качества и производительности.
🧠 Поддерживаемые технологии
InsightFace.
inswapper.
GPEN.
DFM и другие модели — в зависимости от конфигурации проекта.
✨ Улучшение качества изображения
Сглаживание границ заменяемого лица.
Растушёвка маски.
Экспериментальная поддержка смешивания изображений.
Расширенная область обработки лица.
Настройка параметров обработки.
👄 Обработка области рта

Специальная маска позволяет сохранить естественные движения рта и отображение зубов исходного изображения, что может улучшать визуальное качество результата.

🎙️ Voice — преобразование голоса в реальном времени

Модуль Voice основан на технологии RVC (Retrieval-based Voice Conversion) и предназначен для преобразования голоса в режиме реального времени.

Модуль позволяет использовать голосовые модели для обработки звука с микрофона и вывода результата в виртуальное аудиоустройство.

Возможности Voice
🎙️ Преобразование голоса в реальном времени.
⚡ Низкая задержка при обработке звука.
🧠 Поддержка голосовых моделей .pth.
📂 Поддержка индексов .index.
🎚️ Настройка параметров преобразования.
🎧 Вывод обработанного звука через виртуальный микрофон.
🎮 Использование в играх, звонках и стримах.
🖥️ Графический интерфейс для работы с голосом.
Поддерживаемые сценарии

Преобразованный голос можно использовать в приложениях, поддерживающих выбор аудиоустройства:

OBS Studio.
Discord.
Zoom.
Игры с поддержкой внешнего микрофона.
Программы для видеоконференций.
Стриминговые платформы.

Фактическая задержка и качество преобразования зависят от используемой модели, аппаратного обеспечения и настроек обработки.

🧪 Подготовка и обучение голосовых моделей

В состав Voice входят инструменты для подготовки данных и обучения собственных голосовых моделей.

Доступные инструменты

Для Camera и Voice используются отдельные виртуальные окружения Python, поскольку модули имеют разные зависимости.

🏠 Установка Deep Live Studio

Перейдите в корневую папку репозитория:

cd Deep-Live-Cam-and-Voice

Создайте виртуальное окружение:

python -m venv venv

Активируйте его:

venv\Scripts\activate

Установите зависимости основного приложения:

pip install -r requirements_studio.txt

Если файла requirements_studio.txt нет в вашей версии репозитория, проверьте зависимости, используемые в deep_live_studio.py.

📷 Установка Camera

Перейдите в папку Camera:

cd Camera

Создайте виртуальное окружение:

python -m venv venv

Активируйте его:

venv\Scripts\activate

Установите зависимости:

pip install -r requirements.txt
📦 Установка моделей

Загрузите необходимые модели и поместите их в папку models.

Примеры моделей:

Camera/
└── models/
    ├── gfpgan-1024.onnx
    └── inswapper_128_fp16.onnx

Названия и расположение моделей должны соответствовать требованиям конкретной версии Camera.

▶️ Запуск Camera

Для запуска с использованием NVIDIA CUDA:

python run.py --execution-provider cuda

Другие варианты:

python run.py --execution-provider cpu

Также могут поддерживаться:

directml
openvino
coreml

Поддержка конкретного провайдера зависит от операционной системы и установленных зависимостей.

🎙️ Установка Voice

Перейдите в папку Voice:

cd ..\Voice

Создайте виртуальное окружение:

python -m venv .venv

Активируйте его:

.venv\Scripts\activate
📦 Установка зависимостей

Выберите файл зависимостей в соответствии с вашим оборудованием.

NVIDIA CUDA 12.8
pip install -r requirments_cu128_py312.txt
NVIDIA CUDA 11.8
pip install -r requirments_cu118_py312.txt
Только CPU
pip install -r requirments_cpu_py312.txt

Проверьте точное написание названий файлов в вашей версии репозитория. В некоторых версиях используется requirements вместо requirments.

▶️ Запуск Voice
python realtime_gui.py

Также можно использовать готовый ярлык Voice Changer, если он предусмотрен сборкой проекта.

🎬 Использование Deep Live Studio
1. Запуск приложения

Запустите файл:

Deep_Live_Studio.vbs

Скрипт запускает deep_live_studio.py через Python из виртуального окружения venv.

Это позволяет открыть приложение без отдельного окна консоли.

2. Настройка камеры
Откройте раздел «Камера».
Выберите исходное изображение лица.
Выберите необходимые параметры обработки.
Запустите обработку видеопотока.
Настройте виртуальную камеру при необходимости.
3. Настройка голоса
Откройте раздел «Голос».
Выберите необходимую голосовую модель .pth.
При наличии подключите соответствующий .index.
Выберите микрофон.
Настройте параметры преобразования.
Запустите обработку голоса.
4. Запуск всех модулей

На главном экране «Студия» можно использовать:

Быстрый запуск — запуск сохранённой конфигурации.
Запустить всё — запуск всех доступных модулей.
5. Подключение к OBS Studio
Откройте раздел «OBS / Вывод».
Настройте виртуальную камеру.
Настройте виртуальный аудиовыход.
Откройте OBS Studio.
Добавьте устройство захвата видео.
Выберите виртуальную камеру Deep Live Studio.
Добавьте источник аудио и выберите виртуальный микрофон.

После настройки обработанные видео и аудио можно использовать в OBS и других совместимых приложениях.
